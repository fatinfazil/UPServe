# Chat Feature Documentation

## Overview
The chat feature allows users to send real-time messages to each other within the app. All chat data is stored in Firebase Firestore, providing real-time synchronization across devices.

## Architecture

### Models
- **ChatMessage** (`lib/models/chat_message.dart`): Represents a single message in a conversation
  - Fields: id, conversationId, senderId, senderName, text, timestamp, isRead

- **ChatConversation** (`lib/models/chat_conversation.dart`): Represents a conversation between two users
  - Fields: id, participantIds, participantNames, lastMessage, lastMessageSenderId, lastMessageTime, unreadCount

### Services
- **ChatService** (`lib/services/chat_service.dart`): Handles all Firestore operations for chats
  - `getOrCreateConversation()`: Creates or retrieves a conversation between two users
  - `sendMessage()`: Sends a message and updates conversation metadata
  - `getMessagesStream()`: Real-time stream of messages for a conversation
  - `getConversationsStream()`: Real-time stream of all conversations for a user
  - `markMessagesAsRead()`: Marks messages as read and resets unread count
  - `getUsersStream()`: Stream of all users (excluding current user)
  - `deleteConversation()`: Deletes a conversation and all its messages

### Pages
1. **ConversationListPage** (`lib/screens/conversation_list_page.dart`)
   - Displays all active conversations for the current user
   - Shows unread message count and last message preview
   - FAB button to start new chat
   - Navigate to ChatPage when conversation is tapped

2. **UserListPage** (`lib/screens/user_list_page.dart`)
   - Lists all users in the app (excluding current user)
   - Search functionality to find users by name or email
   - Creates or opens conversation when user is selected

3. **ChatPage** (`lib/screens/chat_page.dart`)
   - One-on-one chat interface
   - Real-time message updates using Firestore streams
   - Message read receipts (single/double check marks)
   - Automatic scroll to bottom on new messages
   - Mark messages as read when page is opened

## Firestore Structure

```
conversations/{conversationId}
  ├── participantIds: [userId1, userId2]
  ├── participantNames: { userId1: "Name1", userId2: "Name2" }
  ├── lastMessage: "Last message text"
  ├── lastMessageSenderId: "userId"
  ├── lastMessageTime: Timestamp
  └── unreadCount: { userId1: 0, userId2: 2 }

messages/{messageId}
  ├── conversationId: "conversationId"
  ├── senderId: "userId"
  ├── senderName: "User Name"
  ├── text: "Message text"
  ├── timestamp: Timestamp
  └── isRead: false
```

### Conversation ID Format
Conversation IDs are generated by sorting the two user IDs and joining them with an underscore:
```
conversationId = "{smallerUserId}_{largerUserId}"
```
This ensures consistency regardless of who initiates the conversation.

## Features

### Real-time Messaging
- Messages appear instantly using Firestore streams
- No manual refresh required
- Automatic synchronization across devices

### Unread Message Tracking
- Each conversation tracks unread count per participant
- Badge shows unread count on conversation list
- Messages marked as read when conversation is opened
- Visual indicators (bold text) for unread conversations

### Message Status
- Single check mark: Message sent
- Double check mark: Message read by recipient
- Blue double check mark: Visual confirmation of read status

### User Interface
- Clean, modern design with consistent color scheme
- Message bubbles with rounded corners
- Timestamps for all messages
- User avatars with initials
- Search functionality for finding users
- Empty state messages for better UX

## Usage

### Starting a Conversation
1. Navigate to ConversationListPage
2. Tap the FAB (+) button
3. Select a user from UserListPage
4. Start chatting in ChatPage

### Viewing Conversations
1. Open ConversationListPage
2. See all active conversations sorted by most recent
3. Unread count badge shows new messages
4. Tap any conversation to open ChatPage

### Sending Messages
1. Type message in the text field
2. Tap send button or press Enter
3. Message appears immediately in the chat
4. Recipient sees the message in real-time

## Integration

To add the chat feature to your app navigation:

```dart
// Navigate to conversation list
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => const ConversationListPage(),
  ),
);
```

## Security Considerations

### Firestore Rules (Recommended)
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Users can read all user profiles
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth.uid == userId;
    }

    // Users can only access conversations they're part of
    match /conversations/{conversationId} {
      allow read, write: if request.auth != null &&
        request.auth.uid in resource.data.participantIds;
    }

    // Users can only access messages in their conversations
    match /messages/{messageId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null &&
        request.auth.uid == request.resource.data.senderId;
      allow update: if request.auth != null;
    }
  }
}
```
